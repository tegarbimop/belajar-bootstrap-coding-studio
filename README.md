# Belajar Bootstrap - Coding Studio

Repositori ini berisi kumpulan latihan dan praktik pembuatan halaman web menggunakan **Bootstrap 5** yang dipelajari melalui kursus di **Coding Studio**.

## Daftar Materi / Proyek
- **index.html** : Latihan dasar komponen umum Bootstrap (Accordion, Card, Modal, dll).
- **component.html** : Latihan pembuatan komponen Navbar responsif dan kustomisasi tombol.
- **style.css** : File CSS tambahan untuk melakukan *override* atau styling kustom pada komponen Bootstrap.

## Cara Menjalankan
1. Pastikan Anda memiliki ekstensi **Live Server** di Visual Studio Code.
2. Buka salah satu file HTML (misal `component.html`).
3. Klik kanan lalu pilih **"Open with Live Server"**.
